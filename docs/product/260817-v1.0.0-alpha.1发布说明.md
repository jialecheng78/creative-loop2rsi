# Creative RSI Studio v1.0.0-alpha.1 发布说明

> 发布状态：GitHub Pre-release 正文草案。目标 tag 为 `studio-v1.0.0-alpha.1`；只有 GitHub Release 页面出现目标 tag、三个附件及其 SHA256 后，才表示版本已经发布。本文不证明 Release 或 tag 当前存在。

Creative RSI Studio 是一个中文优先、本地优先的创作系统实验室。它帮助用户从多项独立作品中的重复直接反馈，形成可比较、可采用、可回滚的声明式创作方法。它不是通用写作器，不训练或修改模型权重，也不会自动替用户采用候选或决定核心审美。

## 本版提供什么

- 使用用户自己的 DeepSeek API Key，通过 V4 Flash 完成首次创作、编辑、保留/拒绝和反馈封存。
- 从三项独立作品中规范化后完全相同的直接反馈形成暂时观察。
- 生成一种声明式方法候选，并完成 targeted、regression、held-out 三组 A/B/TIE 盲比。
- 只有用户明确采用后才切换 active method；下一项作品绑定实际使用的方法版本和 guidance 哈希，并可显式回滚。
- 作品、反馈、finding、候选、盲比决定、采用和回滚证据默认保存在本机；应用不接入遥测、广告、云同步或后台生成。
- macOS arm64 打包应用已经完成 Flash `32,768`、packaged smoke 和一次 Computer Use simulated-user 最小闭环验收，详见 [验收报告](260817-32K打包应用与最小闭环验收报告.md)。

## 系统要求与下载

- macOS 13 或更高版本；
- Apple Silicon arm64；
- 可访问 DeepSeek 官方 API 的网络；
- 用户自己的 DeepSeek API Key 和可用额度。

本版是 ZIP 技术预览，不是 DMG 或安装器。Release 只应包含以下三个附件：

| 附件 | 用途 |
|---|---|
| `Creative-RSI-Studio-1.0.0-alpha.1-macos-arm64.zip` | 用户主下载；ZIP 内只有 `Creative RSI Studio.app` |
| `SHA256SUMS.txt` | 绑定主 ZIP 与 evidence ZIP 的 SHA256 |
| `Creative-RSI-Studio-1.0.0-alpha.1-evidence.zip` | manifest v2、path-free delivery manifest、SBOM、许可证和审计过的源码证据 |

不要从第三方网盘、聊天附件或重新打包的镜像下载。文件名、大小或 SHA256 与 Release 页面不一致时停止安装。

## 安装与首次打开

1. 下载主 ZIP 和 `SHA256SUMS.txt`，核对 SHA256。
2. 双击解压，把 App 拖入“应用程序”。
3. 首次打开时，对 App 按住 Control 点击并选择“打开”；仍被拦截时，只在“系统设置 → 隐私与安全”中对刚下载的 Creative RSI Studio 选择“仍要打开”。本包无 Developer ID 签名/公证；匿名 ad-hoc seal 只保证 bundle 一致性。
4. 不要关闭 Gatekeeper，不要执行 `xattr` 绕过，不要安装根证书。App 也不应要求管理员密码或相机、麦克风、蓝牙等无关权限。

完整步骤和停止条件见 [无开发者身份签名的技术预览安装说明](unsigned-preview-install.md)。

## API Key、调用与费用

- 用户需要自行承担 DeepSeek API 用量和费用；项目不赠送额度，也不能替 DeepSeek 保证价格或服务可用性。
- 连接 Key 时会访问 DeepSeek 官方 `/models`；每次创作通常发起一次 `/chat/completions` 请求。网络失败后的受控重试也可能产生调用和费用。
- 编辑正文、保存普通反馈、保留或拒绝作品、盲比选择、采用和回滚不调用模型。
- 正常无重试的候选准备共发起五次 Chat 请求：一次 Builder 请求，以及 targeted candidate、regression candidate、held-out baseline、held-out candidate 四份盲比内容生成。
- 候选准备可能耗时并产生明显费用；系统不会在失败后静默重做可能已经发起或付费的准备。
- 模型请求固定使用 `thinking=enabled`、`reasoning_effort=high` 和单次最多 `32,768` 个总输出 token；达到上限会记为 `OUTPUT_TRUNCATED`，不会把部分内容冒充完整作品封存。

## 隐私、本地数据与卸载

- 创作所需文本会发送到 `https://api.deepseek.com`。DeepSeek 如何处理请求由其公开政策和用户与 DeepSeek 之间的关系决定。
- 用户输入 Key 时，它会在密码输入页的 Renderer 内存中短暂停留，提交后立即清空。后续存储和读取只由 Electron Main 管理，不向 Renderer 回读，也不记录。系统安全存储可用时加密持久保存；不可用时只有用户明确选择“仅本次打开有效”才会使用 Main 进程内存，完全退出应用（⌘Q）后失效。
- Key 不应进入环境变量、命令行、DSH Session、Controller、日志、作品目录或导出包。
- 当前 alpha 的受信 DSH 子进程没有 OS 级强制出网沙箱。受信 Profile 不向模型提供网络、Shell 或动态代码工具，但这不是物理网络隔离。
- 删除 App 不会删除作品、反馈、候选、采用/回滚证据或已加密凭证。本地数据位于 `~/Library/Application Support/Creative RSI Studio/`；清理前先备份需要保留的作品，并在 Finder 中确认目标。
- macOS 只关闭窗口不等于退出，Main 和在途生成可能仍在运行。使用 ⌘Q 完全退出后才不会继续生成。应用没有自动更新，也没有后台“检查更新”；新版本需要用户重新下载。

完整隐私边界见 [PRIVACY.md](../../PRIVACY.md)。

## 安全报告

发现以下问题时请停止使用：哈希不一致、系统提示 App 已损坏、App 要求关闭系统安全能力、出现无关隐私权限、Key 或作品进入公开日志/附件。请通过 GitHub 仓库的 **Security → Report a vulnerability** 私下报告，不要在公开 issue 中粘贴 Key、未发表作品或真实用户数据。详情见 [SECURITY.md](../../SECURITY.md)。

`alpha.1` 公开后不会原地替换同版本附件。任何二进制、安装或安全修复都使用新的版本号，例如 `alpha.2`。
