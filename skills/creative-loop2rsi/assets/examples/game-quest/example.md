# L3 虚构案例：潮汐邮局游戏任务

> 本目录只演示嵌套多 Loop 的配置，不是真实游戏、运行证据或成熟度晋升记录。

## 用户的五项输入

1. 为虚构叙事游戏“潮汐邮局”写一段 12 分钟支线任务，面向喜欢温柔悬疑的玩家。
2. 最小成品包含世界约束补丁、任务结构、可直接实现的对白和两个有后果的选择。
3. 代表任务：玩家要替一座每天忘记昨日潮位的小岛送回一张被退回的明信片。
4. 必须遵守“记忆只能附着在邮票上”的世界规则；不能用旁白替玩家解释谜底，不能出现无后果假选择。
5. 喜欢物件推动叙事和含蓄幽默；不喜欢百科式世界说明与重复确认信息的对白。

## 三个 Loop

1. `maintain-world-rule`：维护该任务需要的最小世界约束，写 `world-rule-patch`。
2. `design-quest-structure`：读取约束并写 `quest-outline`，负责目标、选择与后果。
3. `write-quest-dialogue`：读取约束和结构，写 `quest-dialogue`，不拥有世界事实。

世界规则变化只使依赖它的任务结构和对白失效；对白措辞变化不应反向改写世界规则。每个产物只有一个 owner。

要在真实项目中证明 L3，仍需封存 L2 基线、演练局部重跑、证明未受影响上游哈希不变，并用端到端评价确认不低于 L2。
