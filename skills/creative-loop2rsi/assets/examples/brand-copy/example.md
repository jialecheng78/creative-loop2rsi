# L2 虚构案例：雾岚午后品牌文案

> 本目录只演示 L2 所需的合同、角色和证据计划，不是实际运行、人工校准或成熟度晋升证据。

## 用户的五项输入

1. 为虚构的无咖啡因气泡茶“雾岚午后”写社交平台短文案，面向想减少晚间刺激饮品的年轻上班族。
2. 最小成品是标题加 45–90 字正文和一条温和行动邀请。
3. 代表任务：介绍“烤梨桂花”虚构口味的秋日晚间场景。
4. 必须明确它是饮品；不能声称改善睡眠、治疗焦虑或使用“零负担”等不可证实绝对用语。
5. 喜欢具体生活场景与克制幽默；不喜欢伪诗意堆砌、焦虑营销和命令式购买。

## 为什么达到的目标是 L2 形态

- `copy-producer` 与三个 Judge 分离；
- attempt 计划为不可变，评价与 finding 都引用证据；
- 硬合同、软质量和人类偏好分开；
- 只允许确定性格式修复和责任 Loop 局部重跑；
- 用 `memory-policy.md` 区分已确认偏好与单次教训。

要在真实项目中证明 L2，仍需至少五个样本、硬合同无假通过、人机方向一致率默认不低于 80%，并完成一次局部恢复演练。
