# L1 虚构案例：纸月邮差

> 本目录只演示配置形态，不是实际运行记录，也不能作为任何项目达到 L1 的证据。

本目录本身是一套可由 `loopctl.py validate` 校验的最小项目；运行合同位于 `creative-system/`。它展示 L1 的目标结构，不把声明等级冒充为已有成熟度证据。

## 用户的五项输入

1. 为 9–12 岁读者写一篇奇幻短故事。
2. 最小成品是一篇 900–1400 字、有转折和明确结尾的中文故事。
3. 代表任务：一个怕黑的孩子必须在停电夜送出一封会发光的信。
4. 必须让主角通过行动作出选择；不能靠“醒来发现是一场梦”收尾，不能出现血腥细节。
5. 喜欢具体动作和有代价的选择；不喜欢旁白直接宣布人物已经成长。

## 为什么只搭一个 Loop

故事体量小，当前真实目标只是跑通一次完整的“起草—评价—决定—修改或提交”。构思、起草和润色尚不需要独立 owner，也没有局部恢复收益，因此先保留一个 `draft-story` Loop。

## 试跑方式

用三条不同但同等难度的代表任务试跑，每条最多三个 attempt。每次保留：

- brief；
- 当前稿；
- 硬合同结果；
- 人的审美反馈；
- `revise / commit / stop / escalate` 决定。

至少两条获虚构用户认可且停止条件有效后，才有资格在真实项目中申请 L2；本目录没有这些运行证据。
